# RiverLagNet 当前核心结果

## 一句话结论

真实日尺度数据表明，有向上游河网信息可以带来正的验证集增益，但当前可部署模型远未达到 15%：全 1068 站任务相对同预算无图模型仅提升 **0.09%**，在不读取水质结果而由拓扑预定义的 61 站连续主干上，最佳 8 跳 RiverLagNet 提升 **1.56%**。新的 CrossFormer 受控实验进一步量化出：直接边 attention 提升 **0.49%**，多尺度祖先路径 attention 提升到 **0.79%**，说明 attention 创新有效但幅度仍小。

![河网信息 15% NSE 增益诊断](figures/graph_15pct_diagnostic_v2.png)

这量化的是河网信息的增量预测价值，不是 attention 的因果效应，也不是污染物真实因果传播量。

## 当前硬门槛核验

| 范围 / 方法 | 无图 macro NSE | 加图 macro NSE | 相对提升 | 结论 |
|---|---:|---:|---:|---|
| 1068 站全网，扩展输入，8 跳轨迹传播 | 0.56350 | 0.56401 | +0.09% | 未达 15% |
| 61 站主干，8 跳隐状态轨迹传播 | 0.58394 | 0.59303 | +1.56% | 当前最佳可部署候选，未达 15% |
| 61 站主干，显式时滞输出输送 | 0.58394 | 0.58331 | −0.11% | 丢弃 |
| 61 站 CrossFormer，直接边 ELHSA + TGCF | 0.58420 | 0.58706 | +0.49% | 被多尺度 attention 取代 |
| 61 站 CrossFormer，MAP-LHSA + TGCF | 0.58420 | 0.58882 | +0.79% | 保留 attention 创新，未达 15% |
| 61 站 CrossFormer，MAP-LHSA + DTGFF | 0.58420 | 0.58457 | +0.06% | 目标输送融合丢弃 |
| 训练期拟合、验证期评价的上游线性诊断 | 0.58394 | 0.58467 | +0.13% | 稳定新增信号很低 |
| 仅按训练期筛选的 12 站队列 | 0.49117 | 0.49541 | +0.86% | 验证期仍未达到门槛 |
| 使用真实未来上游误差的 8 跳 oracle | 0.58394 | 0.67813 | +16.13% | 不可部署，不能作为模型结果 |

15% 门槛对 GRU 无图基线对应 NSE `0.67153`，对 CrossFormer 无图基线对应 `0.67183`。只有读取真实未来上游预测误差、并在同一验证结果上拟合和评价的 oracle 超过该门槛；训练期可获得的上游历史与上游本地预测不能复现这一增益。

## 上下游影响的量化边界

- 全网包含 1068 个节点和 1067 条上游→下游边，其中 572 个水头节点没有入边，动态上游消息不可能直接改善这些节点。
- 为排除水头节点稀释，项目按累计旅行时间先验最长路径构建了 61 站、60 边连续主干；选择规则不读取水质值、验证结果或测试结果。
- 主干累计传播时间先验为 153.0 天；8 跳消息传播已经覆盖理论 oracle 首次超过 15% 所需的深度。
- 可部署的训练→验证上游线性诊断最高仅提升 0.13%；按训练期内部留出筛选强关系站后，正式验证提升仍只有 0.86%。这说明训练期上游关系跨期不稳定，而不是单纯模型容量不足。
- MAP-LHSA 把 1–8 跳有向祖先路径、累计旅行时间、离散时滞和预测提前期放入一次联合 sparsemax 路由，使 CrossFormer 增益由 0.49% 增至 0.79%；TGCF 再让本站 Transformer query 选择 GNN 路由头。这是可保留的算法改进，但不是 15% 结果。
- 显式目标空间输送融合将 NSE 降至 0.58457，且训练时间由 578 秒增至 843 秒，因此默认关闭并作为 discard 消融保留。
- 旧 238 节点五种子实验仍证明正确河网方向可产生一致正增益，但平均绝对 ΔNSE 只有 `+0.001337`；该结果支持“存在小幅稳定价值”，不支持“至少 15%”。

## 当前项目判断

继续只调整网络层、隐藏维度或学习率，不能诚实保证 15% 提升。当前数据已经包含本站水质、气象、土壤水和 `dis24`，本站 90 天历史吸收了大部分可预测信息；静态拓扑和近似旅行时间缺少足够的新增、跨期稳定输送信号。

若 15% 仍为硬门槛，项目下一步应优先补充逐河段流量/流速、动态旅行时间、闸坝调度、排污或突发事件、支流汇入负荷等输送过程数据，再重做同预算无图对照。否则正式目标应调整为：

> 量化真实河网信息对 NH3N、CODMn、TP 日尺度预测的增量、适用节点和预测提前期，并如实报告其稳定性与上限。

当前没有启动五种子确认，因为种子 42 的验证筛选未通过 15% 门槛；保留测试集仍未启封。

## RCELA + GMRF 最新正式筛选（2026-07-15）

新的递归 CrossFormer 将创新放在两个位置：RCELA attention 只在真实有向祖先路径上联合选择“路径 × 正时滞”，并在未来阶段只读取历史状态或更早的模型预测状态；GMRF 则把图消息放进每一天的 Transformer 隐状态转移，而不是在 30 日直接解码之后追加小修正。

在 61 站真实日尺度主干河网、seed=42、完全相同训练预算下：

| 模型 | 验证 macro NSE | MAE | RMSE | 相对无图提升 |
|---|---:|---:|---:|---:|
| recurrent CrossFormer，无图 | 0.589238 | 0.128955 | 0.380526 | — |
| recurrent CrossFormer，真实 directed 河网 | **0.595144** | **0.123495** | **0.370148** | **+1.002%** |
| 预设 15% 门槛 | 0.677623 | — | — | +15.000% |

该结果是当前可部署候选中的最高验证 macro NSE，说明“让上游信息参与未来状态演化”比单纯输出后融合更有效，因此 RCELA + GMRF 机制保留。但它仍没有达到 15%，不能扩展为五种子确认，也不能宣称已经实现强河网增益。directed 训练耗时 3562 秒、峰值显存 5.97 GB，无图为 254 秒、0.72 GB；后续改进必须同时减少无效路径时滞候选并提升增益。测试集仍未使用。
